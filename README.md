# Aegean Vessel Tracker

Web application (Dash) for tracking and analyzing vessels in the Aegean Sea,
based on AIS data from [Global Fishing Watch (GFW)](https://globalfishingwatch.org/).

It visualizes vessel trajectories, activity heatmaps and protected areas, and
detects **vessel encounters**, **loitering** behavior (vessels idling at low
speed) and **port visits**.

## Features

| Page | Description |
|------|-------------|
| **Data** | Downloads AIS data from GFW (API key required). |
| **Map & Trajectories** | Vessel trajectories over a date range. |
| **Heatmaps** | Activity density by year / season / vessel type. |
| **Statistics** | Aggregated statistics. |
| **Protected Area** | Vessels entering protected zones (Fourni). |
| **Encounters** | Vessel-to-vessel encounters (< 500 m for ≥ 2 h). |
| **Loitering** | Vessels holding a low speed (adjustable thresholds). |
| **Port visits** | Port visits via the GFW API, aggregated by port. |
| **Tracking & Reports** | Vessel-focused report with AIS gaps, port visits, loitering, encounters, and identity-stable search results. |
| **Watchlist** | Ranks vessels from saved VP reports by risk score so the most suspicious cases stay visible. |
| **Alerts** | Triage view that filters the watchlist to the highest-risk and repeated vessels first. |
| **Vessel Dossier** | Detailed per-vessel history across saved VP reports, with strongest signals and occurrence history. |

## Installation

### 1. Requirements

- **Python 3.11** (recommended)
- **Git**

### 2. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
cd YOUR-REPO
```

### 3. Create a virtual environment

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

> If `requirements.txt` is missing or incomplete, the main packages are:
> `dash`, `dash-bootstrap-components`, `dash-deck`, `pydeck`, `pandas`,
> `geopandas`, `duckdb`, `pyarrow`, `shapely`, `gfw-api-python-client`.
> **`pyarrow` is required** to read Parquet files.

## Data (important)

This repository contains **code only**. The data (from several hundred MB to
several GB) is **not** versioned: it is either re-downloadable from GFW or
regenerable locally.

### What is NOT in the repository

Everything is listed in `.gitignore`:

```
data/            # all data
*.csv            # raw GFW downloads
*.parquet        # raw + precomputed data
*.geojson *.shp  # geographic files (zones, EEZ, Natura 2000)
*.html           # generated maps
```

Three categories, handled differently:

| Type | Location | Reproducible? |
|------|----------|---------------|
| **Raw CSV / Parquet** (`data/raw/`) | downloaded from GFW | ✅ yes, via the **Data** page or the API |
| **Precomputed files** (`data/precomputed/`) | generated by `preprocess.py` | ✅ yes, one command |
| **Geographic files** (`data/gis/`, shapefiles) | provided separately | ❌ no — must be archived / retrieved |

### Getting / regenerating the data

#### Step A — Geographic files (required, not reproducible)

Protected areas, EEZ, territorial waters and Natura 2000 layers cannot be
re-downloaded automatically. Get the separately provided archive and place its
contents in:

```
data/gis/
```

> 📦 **Download link for geographic files:**
> _(to be filled in — e.g. OneDrive / Google Drive link)_

#### Step B — Raw AIS data

Two options:

**Option 1 — Re-download from GFW (recommended)**
Launch the app, go to the **Data** page, enter your API key, choose
country / type / period, then download. Files land in `data/` (CSV) or
`data/raw/` (Parquet partitioned by year).

**Option 2 — Restore an existing archive**
If you saved an archive of the raw data, unzip it so that the
`data/raw/year=YYYY/...parquet` structure is restored.

#### Step C — Regenerate the precomputed files

Once the raw Parquet files are present in `data/raw/`, run **once**:

```bash
python preprocess.py
```

This generates everything the app needs at runtime (heatmaps, trajectories,
filters, statistics, zones) into `data/precomputed/` and `data/gis/`. The app
then only **reads** these files — no heavy queries during use.

## GFW API key

Some features (the **Data** page and the **Port visits** page) require a
Global Fishing Watch API key. You can get one for free from the
[GFW token portal](https://globalfishingwatch.org/our-apis/tokens).

⚠️ **Never put your API key in the code or on GitHub.** Enter it in the
interface when needed. If you want to store it locally, use a `.env` file
(already git-ignored):

```
GFW_API_KEY=your_key_here
```

## Notes

- The project uses **DuckDB** to query Parquet files efficiently.
- Maps on the Map / Heatmap / Protected / Encounters / Loitering / Ports pages
  are rendered with **pydeck** (`dash-deck`).
- Encounter and loitering detection is done locally from the trajectories;
  port visits come directly from GFW events
  (`public-global-port-visits-events`).
